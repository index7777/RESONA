# RESONA — Brand DNA

> Canonical visual and behavioral identity for the RESONA website and product surface.

## 1. Brand position

**RESONA is programmable audio given a visual identity.**

The product is a browser-first sound studio for developers and coding agents. The brand must communicate three ideas at once:

1. **Engineering precision** — deterministic, inspectable, structured audio.
2. **Creative sound design** — synthesis, shaping, iteration, musicality.
3. **A living identity** — RESONA has a dedicated humanized form, without becoming a chatbot or mascot UI.

Primary positioning line:

> **Sound, as code.**

Secondary brand line:

> **RESONA is sound engineered into human form.**

## 2. Brand personality

- Precise
- Quietly confident
- Technical
- Elegant
- Observant
- Experimental without chaos
- Futuristic without neon overload
- Humanized without becoming cute or conversational

The target feeling is **engineering instrument × editorial sci-fi × premium creative software**.

## 3. Visual hierarchy

Use this approximate visual weight:

- 70–80% charcoal / black / graphite
- 10–15% Signal Mint
- 3–6% white / neutral text
- 2–4% Phase Violet
- warning / destructive colors only when semantically required

Signal Mint is the identifying color. Phase Violet supports phase, modulation, selection, or secondary signal activity and must not compete with Signal Mint.

## 5. Graphic DNA

Canonical motifs:

- waveform
- FFT / spectrogram
- routing nodes
- incomplete resonance rings
- signal paths
- technical grids
- phase arcs
- oscilloscope lines
- engineering annotation marks

Rules:

- Treat graphics as information-bearing system language, not decoration.
- Prefer thin lines, restrained glow, controlled density.
- No rainbow spectrum aesthetic unless the visualization genuinely represents spectrum data.
- Avoid generic AI blobs, abstract liquid gradients, cyberpunk city clutter, or random holograms without function.

## 6. Typography direction

Recommended roles:

- Display / marketing: **Space Grotesk** or equivalent geometric grotesk
- Product UI: **Inter** / system sans
- Technical data: **IBM Plex Mono** or equivalent monospace
- Traditional Chinese: **Noto Sans TC** or compatible high-legibility sans

Typography should feel engineered, not sci-fi novelty. Avoid decorative techno fonts for long text or primary product UI.

## 7. Logo system

The logo system should support:

1. RESONA wordmark
2. Resonance Ring mark
3. compact geometric R mark
4. monochrome black / white versions
5. Signal Mint accent version

The core mark language should derive from signal flow + resonance geometry, not musical-note symbols.

## 8. Character relationship

RESONA's character is a **brand embodiment**, not the interaction model.

She may appear in:

- hero artwork
- launch / release artwork
- GitHub social preview
- documentation covers
- splash / intro sequences
- selected empty states
- editorial / campaign visuals

She should not appear as a speaking assistant inside routine controls.

Canonical character rules are defined in `CHARACTER_MASTER.md`.

## 9. Website art direction

The website should feel like RESONA's environment rather than a separate marketing theme.

Use:

- cinematic ultra-wide hero artwork
- restrained motion layers
- signal overlays
- dark technical surfaces
- strong negative space for copy
- precise component spacing
- minimal decorative chrome

Avoid:

- character art behind dense functional controls
- excessive glassmorphism
- large rainbow gradients
- idol / VTuber visual language
- chat bubbles around the character
- over-animated backgrounds

## 10. Copy style

Prefer concise engineering language.

Good:

- Define. Render. Inspect. Ship.
- Sound, as code.
- Deterministic audio for programmable workflows.
- Built for developers. Designed for agents.

Avoid generic marketing phrases such as:

- Unleash your creativity
- Make amazing music with AI
- Your friendly AI music companion

## 11. Source of truth

If generated artwork conflicts with this document or `CHARACTER_MASTER.md`, the written specifications take precedence.
