# RESONA — Character Master

> Canonical character specification for the personified embodiment of the RESONA audio platform.

## 1. Canonical identity

**Name:** RESONA  
**Role:** Personified embodiment of the RESONA software itself  
**Archetype:** Sound engineer × synthesizer avatar × digital sonic lifeform  
**Relationship to product:** She is not an assistant using RESONA. She is RESONA.

RESONA is not a chat mascot, singer idol, VTuber, virtual girlfriend, or generic cyberpunk character. The character exists as the visual embodiment of programmable sound: synthesis, signal routing, analysis, iteration, and resonance expressed as a human form.

## 2. Personality

- Calm
- Precise
- Intelligent
- Reserved
- Observant
- Technically confident
- Slightly mysterious
- Artistically sensitive without becoming theatrical

Avoid exaggerated cuteness, hyperactive expressions, idol gestures, or overtly conversational mascot behavior.

## 3. Physical design

### Face

- Adult woman; mature rather than childlike
- Refined facial structure
- Calm default expression
- Mint / teal-green eyes
- Iris detail may contain subtle concentric-ring or waveform geometry
- Expression range remains restrained

### Hair

- Long charcoal-black hair
- Dark neutral base
- Restrained signal-mint inner highlights / strands
- Optional very small phase-violet reflective accents
- Flowing silhouette that can visually echo signal paths

### Ear module

The ear device is a **custom audio-node module**, not conventional headphones.

Visual references:

- DSP node
- signal routing
- circular resonance geometry
- compact modular hardware
- small illuminated mint core

It represents receiving, resolving, and connecting the sound world.

### Resonance Core

A small signature module located around the upper chest / sternum.

Rules:

- Circular or incomplete-ring geometry
- Signal-mint illumination
- Fine metallic frame
- May include waveform / pulse detail
- Must remain compact and engineered rather than magical

Meaning: the core audio engine of RESONA — synthesis, processing, reconstruction, resonance.

## 4. Costume

### Direction

Technical fashion / futuristic studio operator.

The silhouette should feel like an engineered audio instrument translated into clothing.

### Core elements

- Charcoal / black fitted base layer
- Layered modular technical jacket
- Asymmetric panels
- Fine routing-line graphics
- Utility modules / compact belt components
- Long vertical panels or straps for recognizable silhouette
- Small RESONA wordmark application allowed
- Brushed metal / matte technical textile / translucent mesh / luminous mint glass accents

### Silhouette

The silhouette is a primary identity asset.

Keywords:

- Layered
- Asymmetric
- Long vertical flow
- Sharp geometry
- Technical elegance
- Controlled motion

Even as a dark silhouette, the character should remain recognizable through hair flow, jacket layering, long panels, and compact audio-node details.

## 5. Signature palette

| Token | Hex | Role |
|---|---|---|
| Charcoal Black | `#0B0F14` | Dominant clothing / dark field |
| Graphite | `#2A2F36` | Secondary material / structure |
| Signal Mint | `#5EF2CE` | Primary identity signal |
| Phase Violet | `#806CFF` | Secondary phase / modulation accent |
| Off White | `#F4F6F8` | Documentation / contrast |

Signal Mint is the character's dominant identifiable accent. Phase Violet is secondary and must not compete with it.

## 6. Expression set

Canonical minimum expression set:

1. **Neutral** — calm, direct, observant
2. **Focused** — listening / analyzing
3. **Confident** — faint controlled smile

Do not use exaggerated anime reaction faces as canonical brand imagery.

## 7. Visual motifs

RESONA imagery may use:

- waveform
- spectrogram
- FFT / frequency fields
- DSP nodes
- routing lines
- grids
- phase rings
- signal pulses
- oscilloscope geometry
- technical annotation marks

These motifs should behave as engineering language, not decoration.

## 8. Prohibited drift

Do **not** reinterpret RESONA as:

- idol singer
- DJ mascot
- VTuber
- chatbot avatar
- schoolgirl
- fantasy mage
- generic neon cyberpunk heroine
- kawaii mascot
- character covered in music-note symbols
- character holding a microphone by default
- character wearing oversized consumer headphones by default

Avoid rainbow-neon overload. The brand remains charcoal-first with Signal Mint as the identifying energy color.

The character is part of the visual identity, not the primary UI interaction model.

Good uses:

- website hero
- launch artwork
- GitHub social preview
- release artwork
- splash / onboarding
- empty-state illustration
- documentation cover
- community / merchandise visuals

Avoid placing a talking character in every workflow or turning standard controls into conversational UI.
